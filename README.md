# ESP32-C3 Sensor-Devboard

ESP32-C6 50x50 board made to test smd reflow techniques with various components packages (QFN, HTSOP, WSON, USBC, SOT, SOIC, 0201)

## IC List

- ESP32-C6 (Main MCU)
- W25Q128JVSIQ (16MB program storage spi flash)
- 2x TMP117 (I2C temperature sensor)
- BMP581 (I2C/SPI pressure sensor)
- LMR36520 (wide Vin buck converter)
- LM317A (high Vin LDO)
- AP2112K (MCU LDO)
- 2450AT18A100E (2.45GHz Ceramic chip antenna)
- 01005 resistors
